# Glosario de abreviaturas y sinónimos

Palabras informales del equipo de Acme.

- **WC / wc**: web component que carga el shell.
- **No carga / no anda**: el web component no aparece en el shell.
- **Shell**: aplicación Angular que carga los web components.
- **MR**: merge request. Aprobar un MR es dar el visto bueno de la revisión.
- **main / master**: rama principal de un repositorio.
- **Lib**: librería compartida del registry npm interno (`@acme/ui-kit`).
- **CDN**: de donde el shell descarga el bundle de cada web component.
- **Manifiesto**: `manifest.json` de cada ambiente; define qué versión carga el shell.
- **Pipeline / job**: ejecución de CI; un job es un paso del pipeline.
- **QA / prod**: ambientes de pruebas y de producción.
- **Guardia**: guardia de Plataforma, para incidentes urgentes.
- **Backup humano**: quien cubre a Arquitectura Frontend en vacaciones.
